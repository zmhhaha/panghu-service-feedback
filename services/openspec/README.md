## 已保存的需求

| 字段 | 记录 |

第一阶段覆盖中文TTS、音色语速与读音修正、试听和上传替代配音、音频候选与明确采用、按文稿版本关联、局部失效、迟到任务保护、按实际音频时长调整镜头及字幕、项目预览和带声音MP4。第二阶段覆盖音乐音量、裁剪、淡入淡出、旁白时降低音乐音量、响度及削波检查。

相应普通用户反馈见[视频服务条目 VID-008～VID-010](../video-service/README.md#vid-008)。直接成片需求也与VID-001有关。

## 需要保留的边界

- 原有 `add-svg-html-video-workbench` 首版规格将TTS、MP4、音画同步排除在首版范围外。新提案记录的是后续能力，不表示原首版任务尚未按范围完成。
- 提案创建成功、19项待办和规格校验通过，只能证明需求已被记录并通过当时的规格检查，不能证明功能已实现。
- 具体提案可能需要服务登录后才能查看。本仓库保留名称、变更标识和公开可读的需求摘要，避免只有具备登录权限的人才能理解反馈。
- 本会话没有对OpenSpec的通知送达、维护者阅读、实施排期或状态回写进行验证，因此不将这些能力记为成功或缺陷。

## 后续跟踪建议

建议在实施记录中引用本仓库稳定条目ID；完成后记录部署版本、实际复测日期和产物结果。这样可以区分“需求已登记”“维护者报告已修复”和“普通用户流程已验证”，并减少不同服务间复制同一问题却丢失状态的情况。这是本仓库的整理建议，不是对OpenSpec现有实现的审计结论。
